# Matched B1 Pure-PL Baseline versus AIE-FlashStream

This directory contains the raw board evidence for the paper comparison.
Both designs use B1/S32/HQ32/HKV8/D128, seed 7, BF16 I/O and the Host timing
scope H2D + kernel + D2H.

Each of the ten samples per design is an independent process and one kernel
launch. The VCK5000 is reset, polled until ready and allowed a two-second
enumeration-settle interval before each launch.

- `pure_pl_v1/`: ten verified Pure-PL baseline samples
- `v21_pv6/`: ten verified AIE-FlashStream samples
- `SHA256SUMS`: hashes for immutable experiment metadata and raw CSV/JSON/logs

The campaign was generated by
`scripts/benchmark_pure_pl_v1_matched_b1.sh` and
`scripts/benchmark_v21_pv6_matched_b1.sh`. Aggregate paper values are in
`results/final/comparison_summary.json`.

This protocol measures independent cold requests. It does not establish
sustained throughput because the accelerator stalls on a second invocation without reset.
